Goel backend design2 / 8 · Data movement
Database + identity

Table prefixes & login

How to read a table name

Ref_*Shared masters — jobs, our companies
Fact_*Trucking events — tickets, photos
App_*Users, roles, settings, files
Siteline_ / Clearstory_ / Trimble_ / Connecteam_Vendor copies — not CRM
Bid_*Estimator data with no Ref_* home
Do not invent a second “our companies” or “bidding haulers” table. Bid header FKs: Bids.OurEntityId → Ref_OurEntities, optional Bids.JobId → Ref_Jobs.

Auth flow

Source is ours: App_Users, App_Roles, App_Permissions. API /auth, /admin/*.

Lookups

Dashboard dropdowns from Ref_Jobs, Ref_Materials, haulers Ref_ExternalCompanies, sites, Ref_OurEntities → GET /lookups/*. Bidding lists (teams, spec systems…) → GET /lookups/bidding/* — same style, Bid_* tables.
